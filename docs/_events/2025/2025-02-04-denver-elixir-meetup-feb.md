Speaker: Jacob Luetzow, Elixir Mentor

Talk: The Cost of Ecto Preload

1.  Start with a simple example showing why preload is great (the “happy path”)
2.  Demonstrate how it becomes problematic as relationships and data grow (n+1)
3.  Use real-world examples to show the performance impact
4.  Introduce Dataloader as the solution
5.  Show before/after metrics to demonstrate the improvement

This event is fully remote, see the Zoom link to join.
