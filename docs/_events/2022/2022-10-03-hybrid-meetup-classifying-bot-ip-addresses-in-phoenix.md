Meetup schedule: 6:00 - 7:00 – Main Discussion with Michael Lubas, Paraxial.io

    Malicious traffic from bots is a daily occurrence for every site on the internet. One method for defense is determining if a client's IP belongs to a rented cloud server, because that's a strong indication the client is a bot, and shouldn't be sending login attempts.

    This talk will use the bot detection example to explore several topics related to Phoenix. These include how to store IP prefixes efficiently for fast lookup, the radix tree data structure, and why persistent_term is better than ETS for this task.

    This talk is based on the blog post - https://paraxial.io/blog/cloud-ips
