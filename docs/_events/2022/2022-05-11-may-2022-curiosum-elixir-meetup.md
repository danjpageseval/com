Join the Elixir enthusiasts community during our regular meetups!

Speakers

Michał Buszkiewicz A FRAMEWORK FOR UNIFIED AUTHORIZATION IN ELIXIR Expert in Elixir, Phoenix Framework and related technologies. Before that, he cut his teeth on designing Ruby on Rails applications, with a love for out-of-the-box solutions. A developer trainer in Ruby, Rails, Git, SQL, JavaScript, currently, inside Curiosum, he trains junior Elixir developers.

About the presentation: There are numerous authorization libraries for Phoenix Framework - Michał will show you why none of those does it right and how we’re crafting the ecosystem’s first access control library that integrates seamlessly with both Plug and LiveView and perhaps more than that.

Miguel Cobá ELIXIR, KUBERNETES AND MINIKUBE Miguel Cobá is a Software Developer living in Barcelona. He writes code by day and books by night. He currently writes software using Elixir and Elm and has written two books about Elixir and a book for helping developers write their own technical books.

In the presentation, Miguel will use a sample Elixir application to create a cluster of nodes and he’ll deploy it to a minikube cluster. Then he will scale the cluster up and down and we’ll see the cluster adapt automatically.
