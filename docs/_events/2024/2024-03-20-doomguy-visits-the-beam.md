🇬🇧 The speaker is based in Lisbon and will present remotely, but we will physically meet in Prima’s offices. Talk and follow-up discussion will be held in English 🇬🇧

About the talk

Let’s observe how process supervision works like we were inside the BEAM! The BEAM provides the amazing process-spawning capabilities that come from the very early days of Erlang. Elixir provides a minimal API over the powerful supervisor abstraction, but all that power comes from Erlang. We’ll talk about the different supervision strategies available, learn a bit about them and then connect the BEAM to a running Doom game. In the end we will ask Doomguy’s help to control some misbehaving BEAM processes.
