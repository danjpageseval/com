Onorio Catenacci on ‘Pattern Matching And Decomposition in Functional Programming Languages’

A common feature of many programming languages is the idea of not only matching a pattern but decomposing values into portions of the pattern match. For instance, we might have code of this sort: list = \[1,2,3,4,5\] \[head\|tail\] = list

# head = 1

# tail = \[2,3,4,5\]

We’ll first discuss what we mean by “pattern matching” followed by looking at examples in a few functional languages. By examining examples in a few languages we hope to get at what’s essential and what’s simply designer preference in this particular meta-feature.
