This time at the Copenhagen Elixir Meetup we’ll experiment with running a collaborative coding workshop focused around Livebook and working with binaries and GenServers.

We’ll use these tools to build a system for driving a LEGO robot around. Come join if you’re up for doing a bit of collaborative coding and experimenting with:

Binaries and GenServers WebBluetooth and the LEGO Wireless Protocol Collaborating in Livebook

All you need to bring is your Laptop and a browser :)

Note: This is not a remote meetup
