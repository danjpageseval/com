Speaker: Chris Nelson, Co-Founder and Principal Engineer at Launch Scout

Talk: Extending the reach of Elixir with LiveState

LiveState is a project designed to make it easy to use Elixir in more places. By taking a client agnostic approach to rendering, we give you a LiveView like developer experience but let you do so in places you might not have thought possible. Building an application to embed on a github pages micro site? Need a wordpress plugin but want it powered by Elixir? LiveState has you covered. In this session, we’ll introduce the core concepts of LiveState. We’ll dig into the libraries in the LiveState ecosystem and show how they fit together. And finally, we’ll work through code examples that show you how to build LiveState applications that can live anywhere from a single html file to a full CMS.
