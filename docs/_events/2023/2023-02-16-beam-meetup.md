> Talk 1: Introducing Gleam - Peter Saxton Gleam is a fast, friendly, and functional language for building type-safe, scalable systems. This new language takes inspiration from strongly typed languages such as Haskell, Rust and Elm to help BEAM programmers manage complexity and develop with confidence. We’ll take a look at what Gleam offers, how it’s made, and how it complements and interoperates with other BEAM languages.

> Talk 2: Microbenchmarking on the BEAM - Daniel Szoboszlay Benchmarking is a critical part of data driven development.

Can my system handle the predicted peak load for next year? Can I switch to a cheaper instance type without violating my SLA-s? Tools exist to perform the benchmarks that answer these questions. But what about problems on a much smaller scale?

Shall I implement my logic using a gen_server or an ETS table? Maybe a clever algorithm based on atomics? Is it worth inlining a function? It is hard to answer these questions when the differences to measure are small. Running on top of the BEAM means running on top of many layers of complex software, which often results in noisy measurements. We will look into how to control the noise and how to get the clean, comparable results.
