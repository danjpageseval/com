Details: Talk \#1: Thinking like Dialyzer John Högberg, Virtual Machine Developer, Ericsson

Abstract: A brief tour of the counterintuitive nature of Dialyzer, especially when compared to a classical type system. We will go through how Dialyzer reasons about code and give pointers on how to write code that helps Dialyzer find issues.

Speaker bio: John is a member of the Erlang/OTP team at Ericsson, working mainly with the compiler and runtime system. A few of his most notable contributions are the compiler’s type optimization pass, the new file module backend, and large parts of the JIT compiler. John is the current maintainer of Dialyzer.

------------------------------------------------------------------------

Talk \#2: 429 is a beautiful number! \<3 Onno Vos, Lead Engineer, Klarna

Abstract: Join me as we explore the world of rate limiters, the various algorithms available and learn how easy it is to build a rock solid rate limiter! We’ll weigh the pros and cons of each algorithm and look at how easy they are to implement.

Speaker bio: Onno Vos, Lead Engineer at Klarna, has worked on the core servicing system for the past 4 years improving its standardisation, reliability and stability.
