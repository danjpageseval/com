The fact that it’s possible to run the same web platform on embedded hardware as we do on web-scale hardware is amazing on its own. Beyond simply hosting a web app though, Phoenix gives us an even wider toolkit to make embedded development easier and faster. Powell Kinney will show us how to put LiveView, Telemetry, PubSub, and a few other tools in the loop with some real sensors and servos and have some fun with control systems!

Download the Zoom client or browser extension before the event at: <https://zoom.us/download>

The Nerves Project defines a new way to build embedded systems using Elixir.
