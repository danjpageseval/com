ABOUT THE TALK:

With the functional paradigm becoming increasingly popular (ie. React function components), why not learn an actual functional programming language? In this talk, I’ll be going over what functional programming is, how it differs from object-oriented programming, and perform live coding examples using Elixir.

SPEAKER:
